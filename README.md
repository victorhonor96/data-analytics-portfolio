# 📊 Data Analytics Portfolio – Victor Silva

Este repositório apresenta projetos práticos de análise de dados com foco em SQL, Power BI e Python. O objetivo é demonstrar habilidades em análise exploratória, modelagem de dados, construção de dashboards e geração de insights para negócio.

---

## 🚀 Projetos

### 1. 📈 Análise de Custos e Desempenho de Obras

**Ferramentas:** SQL, Excel, Power BI

**Descrição:**
Análise de dados de obras com foco em controle de custos, prazos e desempenho de fornecedores.

**Principais atividades:**

* Modelagem de banco de dados relacional
* Criação de queries SQL (JOIN, GROUP BY, agregações)
* Identificação de desvios de custo e atraso
* Construção de dashboard no Power BI

**Principais insights:**

* Obras com maior desvio de custo concentradas em determinados fornecedores
* Correlação entre atraso e aumento de custo

---

### 2. 🎓 Dashboard de Indicadores Educacionais

**Ferramentas:** Power BI, Excel

**Descrição:**
Dashboard interativo para análise de desempenho de alunos.

**Principais atividades:**

* Tratamento de dados educacionais
* Criação de KPIs (frequência, aprovação, desempenho)
* Desenvolvimento de visualizações interativas

**Principais insights:**

* Identificação de disciplinas com maior taxa de reprovação
* Relação entre frequência e desempenho acadêmico

---

### 3. 🐍 Análise Exploratória de Dados (EDA)

### 4. 🔄 Pipeline de Dados (ETL)

**Ferramentas:** Python, SQL

### 5. 💰 Análise de Preços e Comparação de Mercado

**Ferramentas:** Excel / Python

**Descrição:**
Comparação de preços entre fornecedores para identificar oportunidades de economia.

**Principais atividades:**
