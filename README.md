# 📊 Data Analytics Portfolio

Projeto de análise de dados com foco em SQL, modelagem relacional e visualização interativa.

## 🚀 Tecnologias
- SQL (CTE, JOIN, Window Functions)
- Python (Pandas)
- Streamlit
- SQLite

## 📊 Funcionalidades
- Análise de custos e desempenho de obras
- Indicadores educacionais
- Comparação de preços entre fornecedores

## 🧠 Destaques Técnicos
- Modelagem de dados relacional
- Queries SQL avançadas
- Pipeline ETL com Python
- Dashboard interativo publicado online

## ▶️ Como rodar
```bash
python create_db.py
streamlit run app.py
